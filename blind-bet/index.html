진행자 메뉴
경품 A·B·C 실제 내용 (게임 종료 후 공개)

🎲 게임 룰 (30초 요약)

  1. 각자 칩 15개로 시작. 경품 A·B·C는 내용 비공개(끝나고 공개).
  2. 내 차례에 주사위를 눌러 굴리고, 나온 숫자만큼 칩을 A·B·C 중 한 곳에 베팅 → 턴 넘기기.
  3. 같은 경품에 여러 번 걸면 합산. 쓴 칩은 사라져요.
  4. 남은 칩이 주사위 숫자보다 적으면 베팅 못 하고 남은 칩 전부 소멸.
  5. 모두 칩을 다 쓰면 경품별로 판정: 다른 사람과 금액이 같으면 둘 다 무효, 남은 금액 중 최고액이 당첨.
  6. 전부 중복이면 최고 중복액끼리 가위바위보. 아무도 안 건 경품은 주인 없음. 여러 개 당첨도 OK.

핵심: 많이 거는 것보다 남과 안 겹치게 거는 게 중요해요!
