# 블라인드 경품 베팅 (온라인)

참가자 6명 + 관전자 2명이 각자 휴대폰/PC에서 함께 하는 주사위·칩 베팅 게임.

- 진행자가 "새 방 만들기" → 초대 링크를 단톡방에 공유
- 각자 링크로 들어와 이름 입력 후 "참가자로 앉기" 또는 "관전하기"
- 진행자가 "게임 시작" → 차례가 된 사람이 주사위를 굴리고 A/B/C 중 하나에 베팅
- 칩이 모두 소진되면 자동 판정(중복 금액 무효, 전부 중복이면 최고 중복액끼리 온라인 가위바위보)
- 진행자는 경품 실제 내용을 미리 입력해 두었다가 종료 후 공개

진행자 화면이 게임을 운영하므로 게임 끝까지 진행자 탭을 열어 두세요(새로고침해도 이어짐).
실시간 동기화는 공개 MQTT 서버(broker.emqx.io)를 사용합니다. 별도 서버 불필요.
